# 角色机制覆盖

适用于《土豆兄弟》（Brotato）1.2.0.1 和 1.2.0.3，涵盖本体和可下载内容（DLC）的 74 个角色。助手按本局的角色效果、装备和已启用内容判断可执行的操作。

18 个角色的核心机制已覆盖，32 个角色使用明确的近似估值，24 个角色需要手动处理部分或全部自动操作。命中、接敌、掉落和未来收益使用估计。装备和效果变化后的判断以游戏内日志为准。

## 覆盖状态与实际操作

- **核心机制已覆盖**。助手使用游戏参数与职业限制，逐项重算候选装备和属性。
- **核心机制含明确近似**。仍可自动操作，日志会说明活动频率、状态持续时间或目标覆盖的估值依据。电击枪的减速按单个目标的速度损失和恢复速度估计。
- **核心机制未覆盖并限制自动操作**。助手会提示需手动处理的商店、属性或宝箱及具体原因。自动局可以按游戏给出的价格回收可回收的未估值宝箱。

未建模武器不会仅凭已知部分得分就被自动购买或领取。未来随机变异、升档和缺少模型的特殊召唤没有确定收益；已生成的效果从实际武器数据读取。机械零件改造仍由玩家处理。相同数量、品质或属性联动效果由道具带入时使用相同计算入口。

## 换装与属性联动

国王按武器数量和实际品质重算白武惩罚、红武奖励。两把白武合成蓝武会移除两份惩罚。多面手按持有武器数量扣除伤害，独臂按单槽与武器类别加成计算。科技法师的元素联动建筑攻速、技工的元素联动爆炸范围、空槽经验联动均纳入评分。生命商店在游戏的付款接口处向零截断，连续付款保留属性余数。

| 企业家（Entrepreneur） | `gain_pct_gold_start_wave` → 资源投影、经济评分 | 波初清空余额；正利息同样按原生截断，不将本店余款直接带到下店 |
| 军火商（Arms Dealer） | `destroy_weapons` → 资源投影、成长评分 | 武器用于下一波、下店移除；其永久击杀成长只预测这一波，随后属性不借已销毁武器虚构伤害。未知新武器不假定继承 |
| 伤者（Wounded） | `die_in_one_hit` → `_survival` | 正伤害致死；生命、护甲和普通治疗不获得多次承伤收益。闪避、有限免伤、移速和控场仍影响接触风险 |
| 机械人（Droid） | `materials_as_health` → `_survival`、资源投影 | 材料是防护与购买资源；支出减少防护，普通治疗不能补材料。预算扣除参考承伤，承伤率是近似，非保底收入 |
| 材料吸收致命伤害 | `damage_taken_on_materials` → `_survival`、资源投影 | 生命耗尽后才由材料承接溢出，按合计余量估计防护；持续受击与恢复过程仍属近似 |
| 材料属性联动 | `gain_stat_for_every_stat` → `_stat_delta` | 每个候选按实际剩余材料重算，遵守原生截断；不把未来退款提前入账 |

活动收入存在波动时，预算按收入估计的 75% 计算。固定结算单独计算。材料损耗随承伤压力调整，预计余额供锁定、留钱和刷新使用。生命商店与已有锁定也参与预算，后续升级和出售在发生后计入。

## 事件触发与波内成长

| 角色或效果 | 读取与评分 | 覆盖结论与边界 |
|---|---|---|
| 公牛（Bull） | `explode_on_hit` → 事件次数、原生爆炸模型 | 含近似：实际受伤与自伤分开，闪避和免伤不触发，次数受生命及恢复限制；范围命中与受击机会估计 |
| 巫妖（Lich） | `dmg_when_heal` → 有效治疗事件 | 含近似：次数与量独立，满血无缺口、禁疗与材料生命不虚构治疗；治疗时序按缺血供需估计 |
| 幸运星（Lucky） | `dmg_when_pickup_gold` → 拾取次数、幸运缩放 | 含近似：每次拾取按原生概率与取整计算；不把材料金额当次数，随机目标不全归首领 |
| 受虐狂（Masochist）、闪避叠层 | `temp_stats_on_hit/dodge` → 固定一次事件预测后分时段成长 | 含近似：叠层时点区分开局和平均，实测时点可校准；不反复反馈放大事件次数 |
| 暴食（Glutton）的拾取爆炸 | `explode_on_consumable` → 同一爆炸模型 | 含近似：消耗品次数独立于有效治疗；满血爆炸属性成长按发生时点计算 |

同一触发的多个随机目标效果先合并伤害，再计算敌人护甲和溢出。概率分布超过 64 项时合并为期望，爆炸范围和首领受益份额使用有限覆盖估计。观测只在有相关效果时连接受伤、治疗和拾取信号，不记录逐帧战斗日志。缺血动态爆炸等未实现效果不按确定收益计算。
